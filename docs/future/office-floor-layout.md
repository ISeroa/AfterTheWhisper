# Office Floor Exploration Location

## 목표

`Big Office` 환경 에셋을 활용해 반복 진입 가능한 4~6분 분량의 소규모 탐험 지역을 구성한다.

플레이어는 폐쇄된 사무실에 진입해 공간을 자유롭게 탐색하고, 전투와 아이템 획득을 거친 뒤 현재 보상을 지키기 위해 탈출할지 더 탐색할지 판단한다.

이 지역은 일회성 Mission이 아니라 같은 장소에 반복해서 진입할 수 있는 `Exploration Location`으로 취급한다.

## 명칭

- 시스템 개념: `Exploration Location`
- 레벨 에셋명: `L_OfficeFloor`
- 게임 표시명: `폐쇄된 사무실`
- 환경 에셋: `Big Office`

## 핵심 플레이 흐름

```text
Location 선택
→ Office Floor 진입
→ 중앙 오피스 탐색 및 첫 전투
→ 비상계단 확인
→ 사무실 또는 자료실 탐색
→ 중요 물품 획득
→ 비상계단 탈출 지점 활성화
→ 복귀 전투 또는 잔여 공간 탐색
→ 탈출
→ 획득물 정산
→ Location 선택으로 복귀
```

초기 데모에서는 Location 선택과 획득물 정산을 단순 UI 또는 결과 화면으로 대체할 수 있다. 중요 물품은 별도의 키카드 시스템을 추가하지 않고 기존 `ATDItemPickupActor`를 활용하며, 해당 물품 획득을 탈출 가능 조건으로 사용한다.

## 초기 데모 플레이 시나리오

```text
로비에서 시작
→ 중앙 오피스에서 조작 확인 및 첫 교전
→ 통로를 통해 비상계단을 확인하지만 아직 탈출할 수 없음
→ 사무실과 자료실을 탐색하며 탄약·회복 아이템 획득
→ 자료실에서 중요 물품 획득
→ 비상계단 탈출 지점 활성화
→ 중앙 오피스 또는 통로에서 잔여 적과 교전
→ 비상계단으로 복귀해 탈출
```

예상 플레이 시간:

- 조작 확인과 주변 탐색: 약 30초
- 중앙 오피스 첫 교전: 약 60~90초
- 사무실 및 자료실 탐색: 약 60~90초
- 중요 물품 획득 후 복귀 교전: 약 60초
- 비상계단 복귀 및 탈출: 약 30~60초
- 전체 목표: 약 4~6분

플레이 시간을 늘리기 위해 방을 추가하기보다, 목표 확인·탐색·교전·복귀로 같은 공간의 역할이 달라지도록 구성한다.

## 레이아웃 초안

```text
┌──────────┐     ┌──────────────┐     ┌─────────────┐
│ 탕비실    │     │ 사무실        │     │ 자료실       │
│ 회복 아이템│     │ 적 / 탄약     │     │ 중요 물품    │
└────┬─────┘     └──────┬───────┘     └──────┬──────┘
     │                  │                    │
     └──────────┬───────┘             ┌──────▼──────┐
                │                     │ 비상계단     │
        ┌───────▼───────┐             │ Extraction  │
        │ 중앙 오피스     ├───────┐     └─────────────┘
        │ 책상·파티션     │       │
        │ 주 전투 공간    │   ┌───▼────┐
        └───────┬───────┘   │ 통로     │
                │           └───┬────┘
          ┌─────▼─────┐         │
          │ 로비       │     ┌───▼────┐
          │ Start     │     │ 화장실   │
          └───────────┘     │ 선택 공간│
                            └────────┘
```

## 레이아웃 원칙

- 중앙 사무실을 허브로 두고 여러 방을 선택적으로 탐색할 수 있게 한다.
- 시작 지점에서 전체 공간과 탈출 지점이 한 번에 보이지 않게 한다.
- 필수 일직선 경로보다 다시 중앙 공간으로 합류하는 순환 경로를 제공한다.
- 중요 물품을 획득하면 탈출할 수 있게 하되, 모든 선택 공간을 방문하도록 강제하지 않는다.
- 선택 공간에는 탄약, 회복 아이템, 주요 전리품 등 방문할 이유를 둔다.
- 유리벽이나 열린 문을 통해 다른 공간을 미리 보여주되 접근 경로는 바로 드러내지 않는다.

## 공간별 역할

### 로비

- 플레이어 시작 지점
- 진입 방향과 초기 시야 안내
- 첫 전투 전 짧은 안전 구역

### 중앙 사무실

- 전체 이동의 중심이 되는 허브
- 책상과 파티션을 이용한 주 전투 공간
- 여러 방으로 갈 수 있는 선택지 제공
- 반복해서 통과하더라도 경로가 읽히도록 랜드마크 배치

### 사무실

- 두 번째 주요 탐색 및 전투 공간
- 책상과 파티션 배치를 중앙 오피스와 다르게 구성해 다른 전투 형태 제공
- 탄약 또는 중간 가치 전리품 배치

### 탕비실

- 비교적 안전한 보조 공간
- 회복 아이템 또는 소모품 배치
- 필수 통과 공간이 아닌 짧은 선택 탐색 공간으로 구성

### 통로

- 중앙 오피스에서 자료실, 화장실, 비상계단 방향으로 이어지는 전이 공간
- 시야가 길게 열리지 않도록 꺾임과 출입구 위치를 조절한다.
- 중요 물품 획득 전후로 다시 지나가며 긴장감이 달라지는 복귀 경로로 사용한다.

### 화장실

- 짧은 선택 탐색 공간
- 작은 전리품 또는 근거리 기습 가능 지점
- 필수 경로로 사용하지 않는다.

### 자료실

- 높은 가치의 전리품이 있는 위험 지역
- 초기 데모의 탈출 조건이 되는 중요 물품 배치
- 탈출 지점과 가까우나 적 또는 좁은 진입로로 위험도를 높인다.

### 비상계단

- `Extraction Zone` 배치 지점
- 다른 공간과 명확히 구분되는 색상, 조명 또는 Exit 표식 사용
- 중요 물품 획득 전에는 비활성 상태임을 간단한 안내로 전달한다.
- 초기 데모에서는 실제 계단 없이 출입문과 탈출 영역만 구성할 수 있다.

## 적 배치 초안

- 중앙 사무실: 2마리
- 사무실: 2마리
- 자료실 주변: 2마리
- 통로 또는 탈출 복귀 경로: 1마리
- 전체 목표: 6~7마리

적 배치는 고정으로 시작하되, 반복 플레이 변화가 필요해지면 추후 여러 Spawn Point 중 일부를 선택하는 방식으로 확장한다.

## 아이템 배치 초안

- 탕비실: 회복 아이템
- 사무실: 탄약 또는 일반 전리품
- 화장실: 낮은 확률의 소형 전리품
- 자료실: 탈출 조건이 되는 중요 물품

초기 데모에서는 기존 `ATDItemPickupActor`를 사용하며, 획득물 정산과 영구 보관은 범위에서 제외한다.

## AI 및 이동 공간 기준

- 문과 복도는 실제 비율보다 넓게 구성한다.
- 적 두 마리가 서로 완전히 막지 않을 정도의 통로 폭을 확보한다.
- 책상과 파티션 사이에 AI가 갇히는 좁은 틈을 만들지 않는다.
- 중앙 사무실에는 Encircle 이동이 가능한 여유 공간을 남긴다.
- 장식 메시를 배치한 뒤 Player와 AI Collision을 각각 확인한다.
- 유리벽이 총알 Trace와 시야 판정에 어떤 영향을 주는지 확인한다.

## Big Office 에셋 사용 범위

우선 사용할 에셋:

- 바닥, 외벽, 내벽
- 문과 문틀
- 유리벽
- 책상과 파티션
- 회의실 테이블
- 탕비실 카운터
- 자료실 선반
- 안내 데스크와 Exit 표식

완성된 샘플 맵 전체를 복제하기보다 필요한 모듈과 대표 소품을 가져와 새 레벨에 구성한다.

## 블록아웃 작업 순서

1. 기존 테스트 맵을 보존하고 `L_OfficeFloor` 레벨을 준비한다.
2. 바닥과 외벽으로 전체 면적을 확정한다.
3. 중앙 사무실과 주변 방의 경계를 배치한다.
4. 문과 통로를 배치해 로비, 중앙 오피스, 사무실, 자료실, 비상계단의 주요 진행 경로를 만든다.
5. `PlayerStart`와 Extraction 예정 위치를 배치한다.
6. 전 구역 이동과 카메라 가독성을 확인한다.
7. 적을 한 마리씩 추가하며 이동 경로를 확인한다.
8. 각 공간을 구분하는 대표 가구를 배치한다.
9. 조명과 장식은 플레이 흐름 검증 후 추가한다.

## 블록아웃 완료 조건

- 모든 주요 공간을 문제없이 이동할 수 있다.
- 플레이어가 둘 이상의 탐색 경로를 선택할 수 있다.
- 방문하지 않아도 되는 선택 공간이 존재한다.
- 시작 지점에서 주요 전리품과 탈출구가 바로 보이지 않는다.
- 문, 복도, 가구 사이에서 AI가 심하게 막히지 않는다.
- 중요 물품 획득 전에는 비상계단에서 탈출할 수 없음을 이해할 수 있다.
- 중요 물품 획득 후 비상계단으로 복귀해 탈출할 수 있다.
- 탐색, 전투, 아이템 획득, 탈출이 4~6분 안에 끝난다.
- 같은 장소를 다시 플레이해도 최소한의 경로 선택이 가능하다.

## 차후 확장 방향

### 다중 Office Location

`L_OfficeFloor`를 단순히 반복 복제하기보다 공통 환경 모듈과 게임플레이 규칙을 재사용해 서로 다른 Office Location을 구성한다.

예시:

- 소규모 사무실: 낮은 위험도와 짧은 탐색 시간
- 대형 사무실: 넓은 중앙 공간과 다수의 선택 경로
- 임원 사무실: 적은 전투와 높은 가치의 전리품
- 연구 사무실: 좁은 통로와 제한된 시야
- 지하 자료 보관소: 높은 위험도와 주요 전리품

### Location별 차별화 요소

- 방과 통로의 연결 구조
- 진입 및 탈출 지점
- 적의 수와 배치
- 전리품 종류와 가치
- 조명과 시야
- 선택 경로의 위험과 보상
- 예상 탐색 시간

### 공통 시스템 재사용

각 Location은 다음 시스템과 배치 규칙을 공통으로 사용한다.

- PlayerStart 또는 진입 지점
- 적 Spawn Point
- 전리품 Spawn Point
- Extraction Zone
- Location 진입 및 결과 처리
- 위험도와 보상 데이터

장기적으로 Location 설정을 DataAsset으로 분리해 표시 이름, 레벨, 위험도, 예상 보상, 대표 이미지 등을 데이터 기반으로 관리할 수 있다.

### 반복 플레이 확장

초기 버전에서는 적과 아이템을 고정 배치한다. 이후 다음 요소를 단계적으로 추가한다.

1. 여러 Spawn Point 중 일부만 활성화
2. 전리품 위치와 등급 변화
3. 진입 및 탈출 지점 변화
4. 일부 통로의 개방 상태 변화
5. Location별 위험도와 보상 조정

완전한 절차적 생성보다 수작업으로 검증된 레이아웃에 제한적인 변화를 주는 방식을 우선한다.
